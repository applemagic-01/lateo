# Security status

This repository is an early prototype.

Currently implemented:
- Basic mobile UI prototype
- Basic API health endpoint

Not implemented:
- End-to-end encryption
- Anonymous cryptographic identity
- Secure key lifecycle
- Invitation security
- Abuse reporting/moderation
- Production rate limiting
- Secure message storage

Do not use this prototype for sensitive or real-world private conversations. Security features must be designed, implemented using vetted protocols, independently reviewed, and tested before any security claims are made.
